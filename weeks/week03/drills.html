Week 3 · Drills

Lists, Tuples, and Recursion Patterns

As in Week 2, every section has Core (everyone), Practice (more of the same, for fluency), and Stretch (harder variations). Work on paper first, then check in FSI. For every function you write, use the recipe: type, base case ([]), recursive case (x :: rest, trusting f rest), check.

Unless a question says otherwise, use these definitions from the notes:

let rec length xs =
    match xs with
    | [] -> 0
    | _ :: rest -> 1 + length rest

let rec append xs ys =
    match xs with
    | [] -> ys
    | x :: rest -> x :: append rest ys

let rec evens xs =
    match xs with
    | [] -> []
    | x :: rest when x % 2 = 0 -> x :: evens rest
    | _ :: rest -> evens rest

let rec unzip pairs =
    match pairs with
    | [] -> ([], [])
    | (x, y) :: rest ->
        let (xs, ys) = unzip rest
        (x :: xs, y :: ys)

let rec split xs =
    match xs with
    | [] -> ([], [])
    | [x] -> ([x], [])
    | x :: y :: rest ->
        let (odds, evens) = split rest
        (x :: odds, y :: evens)

let rec merge xs ys =
    match xs, ys with
    | [], ys -> ys
    | xs, [] -> xs
    | x :: xs', y :: ys' ->
        if x <= y then x :: merge xs' ys
        else y :: merge xs ys'

A. List or tuple?

Predict FSI’s response: the type and value, or error with a one-line reason.

Core

  1. [1, 2, 3];;
  2. [(1, 2); (3, 4)];;
  3. ("a", 1) :: [("b", 2)];;
  4. 1 :: [2; 3];;
  5. [1; 2] :: [3];;
  6. [1] @ [2];;
  7. fst ("x", 1, true);;
  8. let (a, b) = (1, "two");;

Practice

  1. [[1; 2]; []];;
  2. [1] :: [[2; 3]];;
  3. [];;
  4. System.Math.Max(3, 5);;
  5. System.Math.Max 3;;

Stretch

  1. (1; 2);;. This one is surprising. What happened?
TipAnswers
  1. val it: (int * int * int) list = [(1, 2, 3)]: a list with one element, a triple. The commas made a tuple.
  2. val it: (int * int) list = [(1, 2); (3, 4)]
  3. val it: (string * int) list = [("a", 1); ("b", 2)]
  4. val it: int list = [1; 2; 3]
  5. Error: :: puts an element in front of a list. Here the “list” on the right is [3], an int list, so the element on the left must be an int, but [1; 2] is an int list. To join two lists, use @.
  6. val it: int list = [1; 2]
  7. Error: fst works only on pairs; this is a triple.
  8. val a: int = 1 and val b: string = "two"
  9. val it: int list list = [[1; 2]; []]: a list of lists. The empty list is a perfectly good element.
  10. val it: int list list = [[1]; [2; 3]]: here [1] is an element of the right type, int list.
  11. val it: 'a list: the empty list could be a list of anything, so its type is generic.
  12. val it: int = 5: a .NET method, called with its arguments in parentheses.
  13. Error FS0503: a method needs all its arguments at once. There is no partial application for methods; that’s only for F# functions.
  14. val it: int = 2, with warning FS0020. Inside parentheses, ; does not separate tuple components. It means “do this, then that”. So (1; 2) evaluates 1, throws it away (hence the warning), and gives 2. Python’s (1, 2) needs commas in F# too.

B. Read the type

Write the type FSI reports, without running it.

Core

  1. length from the notes
  2. let swap (a, b) = (b, a)
  3. unzip from the notes
  4. let rec neighbours xs = match xs with x :: y :: rest -> (x, y) :: neighbours (y :: rest) | _ -> []

Practice

  1. merge from the notes. Why is there a when at the end?
  2. isMember from the notes. Why is its when different from merge’s?
TipAnswers
  1. length: xs: 'a list -> int
  2. swap: a: 'a * b: 'b -> 'b * 'a: one pair in, the swapped pair out.
  3. unzip: pairs: ('a * 'b) list -> 'a list * 'b list
  4. neighbours: xs: 'a list -> ('a * 'a) list: both parts of each pair come from the same list, so they have the same type.
  5. merge: xs: 'a list -> ys: 'a list -> 'a list when 'a: comparison. merge uses <=, so the elements must be orderable.
  6. isMember: x: 'a -> xs: 'a list -> bool when 'a: equality. It only uses =, so the elements only need to be comparable for equality. Every type that supports ordering also supports equality, but not the other way round.

C. Trace by hand

Equation style is enough (length ["a"; "b"] = 1 + length ["b"] = …). Write a full, numbered trace for C1.

Core

  1. length ["a"; "b"] (full trace)
  2. append [1] [2; 3]
  3. evens [1; 2; 4]

Practice

  1. unzip [('x', 1); ('y', 2)]
  2. merge [2; 7] [1; 8]

Stretch

  1. split [1; 2; 3; 4; 5]
TipAnswers 
1.   length ["a"; "b"]
   ⇝ 1 + length ["b"]                 (7) rest ↦ ["b"]
   ⇝ 1 + (1 + length [])              (7) rest ↦ []
   ⇝ 1 + (1 + 0)                      (7) [] fits the first rule
   ⇝ 2                                (4)

2.   append [1] [2; 3] = 1 :: append [] [2; 3]
                       = 1 :: [2; 3]
                       = [1; 2; 3]

3.   evens [1; 2; 4] = evens [2; 4]            1 is odd: dropped
                     = 2 :: evens [4]
                     = 2 :: (4 :: evens [])
                     = [2; 4]

4.   unzip [('x', 1); ('y', 2)]
       = let (xs, ys) = unzip [('y', 2)] in ('x' :: xs, 1 :: ys)
       = let (xs, ys) = (['y'], [2])     in ('x' :: xs, 1 :: ys)
       = (['x'; 'y'], [1; 2])

5.   merge [2; 7] [1; 8] = 1 :: merge [2; 7] [8]      2 > 1
                         = 1 :: 2 :: merge [7] [8]    2 <= 8
                         = 1 :: 2 :: 7 :: merge [] [8]
                         = [1; 2; 7; 8]

6.   split [1; 2; 3; 4; 5]
       = (1 :: odds, 2 :: evens)  where (odds, evens) = split [3; 4; 5]
       = (1 :: 3 :: odds', 2 :: 4 :: evens')  where (odds', evens') = split [5]
       = (1 :: 3 :: [5], 2 :: 4 :: [])
       = ([1; 3; 5], [2; 4])

D. Recognise the shape, write the function

Core. The shape is given. Write each function.

  1. Transform each: negateAll [1; -2; 3] = [-1; 2; -3]
  2. Keep some: nonEmpty ["a"; ""; "b"; ""] = ["a"; "b"]
  3. Combine all: countEvens [1; 2; 4; 5] = 2
  4. Stop early: containsZero [3; 0; 1] = true
  5. Each to many: upTo [2; 3] = [1; 2; 1; 2; 3]. Each x becomes [1 .. x].

Practice. First name the shape, then write the function.

  1. sumOfSquares [1; 2; 3] = 14
  2. lastOf [4; 5; 6] = 6. What should lastOf [] do?
  3. replace 0 9 [0; 1; 0] = [9; 1; 9]
  4. allSame [3; 3; 3] = true, allSame [3; 4; 3] = false. What about allSame []?
  5. flattenPairs [(1, 2); (3, 4)] = [1; 2; 3; 4]

Stretch. These need a match on a tuple, or two elements at a time.

  1. take 2 [1; 2; 3] = [1; 2]: the first n elements (or all of them, if there are fewer).
  2. drop 2 [1; 2; 3] = [3]: everything except the first n.
  3. neighbours [1; 2; 3] = [(1, 2); (2, 3)]: each element paired with the next.
TipAnswers 
let rec negateAll xs =                 // transform each
    match xs with
    | [] -> []
    | x :: rest -> -x :: negateAll rest

let rec nonEmpty (words: string list) = // keep some
    match words with
    | [] -> []
    | w :: rest when w <> "" -> w :: nonEmpty rest
    | _ :: rest -> nonEmpty rest

let rec countEvens xs =                // combine all
    match xs with
    | [] -> 0
    | x :: rest when x % 2 = 0 -> 1 + countEvens rest
    | _ :: rest -> countEvens rest

let rec containsZero xs =              // stop early
    match xs with
    | [] -> false
    | x :: rest -> x = 0 || containsZero rest

let rec upTo xs =                      // each to many
    match xs with
    | [] -> []
    | x :: rest -> append [ 1 .. x ] (upTo rest)
let rec sumOfSquares xs =              // combine all
    match xs with
    | [] -> 0
    | x :: rest -> x * x + sumOfSquares rest

let rec lastOf xs =                    // combine all, non-empty
    match xs with
    | [] -> failwith "lastOf: empty list"
    | [x] -> x
    | _ :: rest -> lastOf rest

let rec replace a b xs =               // transform each
    match xs with
    | [] -> []
    | x :: rest when x = a -> b :: replace a b rest
    | x :: rest -> x :: replace a b rest

let rec allSame xs =                   // stop early
    match xs with
    | [] | [_] -> true
    | x :: y :: rest -> x = y && allSame (y :: rest)

let rec flattenPairs pairs =           // each to many
    match pairs with
    | [] -> []
    | (x, y) :: rest -> x :: y :: flattenPairs rest

Shapes: 6 combine all; 7 combine all (with a one-element base case; lastOf [] has no answer, so failwith); 8 transform each (each element is replaced or kept, but there are always as many as before); 9 stop early (&& stops at the first difference; allSame [] is true, since no two elements differ); 10 each to many.

let rec take n xs =
    match n, xs with
    | 0, _ | _, [] -> []
    | n, x :: rest -> x :: take (n - 1) rest

let rec drop n xs =
    match n, xs with
    | 0, xs -> xs
    | _, [] -> []
    | n, _ :: rest -> drop (n - 1) rest

let rec neighbours xs =
    match xs with
    | x :: y :: rest -> (x, y) :: neighbours (y :: rest)
    | _ -> []

take and drop match on the pair n, xs, because both the number and the list decide what happens. The or-pattern 0, _ | _, [] means “n is zero, or the list is empty”.

E. Lists and tuples together

Core

  1. swap (1, "a") = ("a", 1)
  2. sumPairs [(1, 2); (3, 4)] = [3; 7]

Practice

  1. partition [1; 2; 3; 4; 5] = ([2; 4], [1; 3; 5]): split into evens and odds, in one pass over the list. Hint: look at unzip and sumProd.

Stretch

  1. lookupAll "a" [("a", 1); ("b", 2); ("a", 3)] = [1; 3]: every value for a key.
  2. updatePrice "tea" 50 [("coffee", 55); ("tea", 45)] = [("coffee", 55); ("tea", 50)]: a new table with one price changed. Why is “a new table” the only possible answer in F#?
TipAnswers 
let swap (a, b) = (b, a)

let rec sumPairs pairs =
    match pairs with
    | [] -> []
    | (a, b) :: rest -> (a + b) :: sumPairs rest

let rec partition xs =                 // (evens, odds) in one pass
    match xs with
    | [] -> ([], [])
    | x :: rest ->
        let (es, os) = partition rest
        if x % 2 = 0 then (x :: es, os) else (es, x :: os)
let rec lookupAll key table =
    match table with
    | [] -> []
    | (k, v) :: rest when k = key -> v :: lookupAll key rest
    | _ :: rest -> lookupAll key rest

let rec updatePrice key newPrice table =
    match table with
    | [] -> []
    | (k, _) :: rest when k = key -> (k, newPrice) :: rest
    | entry :: rest -> entry :: updatePrice key newPrice rest
  1. Lists are immutable, so “changing a price” can only mean building a new list. Notice how little is actually new: every element before the changed one is copied, but everything after it (rest) is shared, exactly as in the notes’ sharing diagram.

F. Find the bug

Say what happens (error, warning, wrong answer, or crash), and fix it.

Core

  1. let rec length xs =
    match xs with
    | [] -> 0
    | x :: rest -> 1 + length xs
  2. let rec doubleAll xs =
    match xs with
    | [] -> [0]
    | x :: rest -> 2 * x :: doubleAll rest
  3. let rec evens xs =
    match xs with
    | [] -> []
    | x :: rest when x % 2 = 0 -> x :: evens rest

Practice

  1. join ["a"; "b"] gives "a b ":

    let rec join words =
    match words with
    | [] -> ""
    | w :: rest -> w + " " + join rest

  2. Using sum from the notes:

    let scores = [72, 85, 90]
let total = sum scores

Stretch

  1. This maximum “works” on [3; 9; 2]. Find an input where it gives a wrong answer:

    let rec maximum xs =
    match xs with
    | [] -> 0
    | x :: rest -> max x (maximum rest)
TipAnswers
  1. length xs instead of length rest: the list never gets shorter. Stack overflow for any non-empty list.
  2. The base case should be []: the empty list doubled is still empty. doubleAll [1; 2] gives [2; 4; 0], with no warning.
  3. There is no rule for odd elements: warning FS0025, and at run time evens [2; 3] stops with MatchFailureException: The match cases were incomplete. Add | _ :: rest -> evens rest.
  4. The last word gets a space after it. Add a base case | [w] -> w before the general rule.
  5. [72, 85, 90] is a list of one triple, so sum complains: Expecting a 'int list' but given a '(int * int * int) list'. Use ;.
  6. Any list of negative numbers: maximum [-3; -1] gives 0, which isn’t even in the list. 0 isn’t a neutral starting point for max. The fix is the one in the notes: [x] as the base case, and failwith for [].

G. Sorting (Stretch)

  1. Write insert x sorted, which puts x into its place in an already sorted list: insert 4 [1; 3; 5] = [1; 3; 4; 5].
  2. Use insert to write insertion sort: insertionSort [3; 1; 2] = [1; 2; 3]. Hint: trust insertionSort rest to sort the rest.
  3. Now write merge sort using split and merge: split the list in two, sort each half, merge the results. What are the base cases?
  4. Roughly how many steps does insertionSort take on a list of 1,000 elements that is sorted in reverse? And mergeSort? (Only the order of magnitude matters.)
TipAnswers 
let rec insert x sorted =
    match sorted with
    | [] -> [ x ]
    | y :: rest when x <= y -> x :: sorted
    | y :: rest -> y :: insert x rest

let rec insertionSort xs =
    match xs with
    | [] -> []
    | x :: rest -> insert x (insertionSort rest)

let rec mergeSort xs =
    match xs with
    | [] | [_] -> xs
    | _ ->
        let (left, right) = split xs
        merge (mergeSort left) (mergeSort right)
  1. The base cases are the lists that are already sorted: [] and any one-element list ([_]). Splitting them would not make them smaller.
  2. Insertion sort on a reversed list inserts each element at the very end, walking the whole sorted part each time: about 1000^2 / 2 = 500{,}000 steps. Merge sort halves the list about \log_2 1000 \approx 10 times, doing about 1000 steps of merging at each level: about 10{,}000 steps. For a million elements the difference is between half a trillion and about 20 million.
